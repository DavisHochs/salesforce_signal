## ngrok (needed from Phase 4, when Salesforce calls the sender bridge)

1. Create a free ngrok account and install the agent: `winget install ngrok.ngrok`.
2. Add your auth token. It's stored in ngrok's own config, not in this repo:

   ```bash
   ngrok config add-authtoken <token>
   ```

3. Note your free dev domain from the ngrok dashboard (Domains page): ____________
4. Nothing to run yet. In Phase 4, `ngrok http --url=<your dev domain> <bridge port>` exposes the
   bridge, and that URL goes into the Named Credential.
