# D0.1 — Salesforce Developer Edition org

Owner: Davis.

## Steps

1. Sign up for a new Developer Edition org (the edition that includes Agentforce and Data 360):
   https://developer.salesforce.com/signup. Use a username you don't use elsewhere, for example
   `you+signal@yourdomain.dev` (usernames must be globally unique).
2. Verify the email and set a password. Turn on MFA when prompted.
3. In Setup, assign the Data 360 and Agentforce permission sets the welcome guide lists to your
   user. Record the exact permission set names you assigned here:
   - Data 360: ____________________
   - Agentforce / Prompt Builder: ____________________
4. Authorize the CLI. This opens a browser login and stores the token in the CLI's own store,
   not in this repo:

   ```bash
   sf org login web --alias signal-dev --set-default
   sf org display --target-org signal-dev
   ```

5. Make sure `.env` has `SF_TARGET_ORG=signal-dev` (or the alias you used).
6. Run the smoke test:

   ```bash
   make smoke-sf
   ```

   A report lands in `reports/T0.3-smoke-sf-<timestamp>.json`.

## Done when

- [ ] `make smoke-sf` prints PASS
- [ ] Permission set names recorded above
- [ ] Limits worksheet started (`docs/limits-worksheet.md`)
