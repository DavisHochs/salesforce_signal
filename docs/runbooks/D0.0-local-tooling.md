# D0.0 — Local tooling (Windows)

Owner: Davis. The agent never handles secrets; these steps install tools only.

Found on this machine (2026-10-31): Python 3.12 (`py -3.12`), git, GitHub CLI, Node 22.
Missing: `make`, Salesforce CLI (`sf`), Docker.

## 1. make

```powershell
winget install ezwinports.make
```

Open a new terminal, then check with `make --version`. Run `make` targets from Git Bash or PowerShell.

## 2. Python virtual environment

From the repo root:

```bash
make venv
make install
```

`make install` installs the project plus ruff, pytest and pre-commit, and turns on the
pre-commit hooks (ruff and gitleaks run on every commit).

Without make: `py -3.12 -m venv .venv`, then `.venv\Scripts\python -m pip install -e ".[dev]"`.

## 3. Salesforce CLI

```powershell
npm install --global @salesforce/cli
sf --version
```

## 4. Docker (for Mailpit)

Install Docker Desktop: `winget install Docker.DockerDesktop`, then start it once.
Then `make mailpit-up` and open http://localhost:8025.

No Docker? Mailpit also ships as a single binary (github.com/axllent/mailpit releases).
Run `mailpit.exe`; it uses the same ports (SMTP 1025, UI 8025).

## 5. Local env file

```bash
cp .env.example .env
```

Fill values only in `.env`, which git ignores.
