1. In `.env` (never in the repo), set:

   ```
   TYPESAFE_API_KEY=<your key>
   DECISION_PROVIDER=jev
   ```

   `TYPESAFE_BASE_URL` and `JEV_MODEL` already have defaults in `.env.example`.
2. In the TypeSafe console, set a monthly spend cap and usage alerts if the console offers them.
   Record the values below. If it has no cap, record that, and we'll rely on small run sizes.
   The expected cost is cents per run: about $0.042 per million input tokens (vendor-reported).
3. Run the smoke test:

   ```bash
   make smoke-jev
   ```

   The report in `reports/T0.2-smoke-jev-*.json` should show `"provider": "jev"` and
   `"counts_for_gate": true`.
